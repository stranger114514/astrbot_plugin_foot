一款为 AstrBot 开发的简单整活插件，帮助明日方舟玩家挑选今天美食（bushi）

🎯 功能特点

- 三种触发词：`看看脚` / `看看足` / `看看jio`，带斜杠、@机器人、或群聊裸发都能触发
- 按角色点名：`看看脚 阿米娅` 只抽指定角色（模糊匹配）
- 193 名干员全覆盖：全角色（仅跳过无脚的机器人 Lancet-2 / Castle-3 / THRM-EX 与「预备干员」占位）
- 54 名高人气角色专属文案：阿米娅、凯尔希、陈、德克萨斯、斯卡蒂、银灰、塞雷娅、年、夕、W、煌……结合游戏设定写的风味故事
- 脚臭吧风味输出：一段「故事 + 口感描述」，如「尝起来香香软软的」「闻起来清冽」
- 只留脚部分图：193 张官方精一立绘裁到脚/腿部分，本地随插件发送，不依赖外链
- 可自定义：编辑 `data.py` 即可加角色文案、加口感描述、加图

📦 安装方法

方法一：WebUI 上传（推荐）

1. 打开 AstrBot 的 WebUI
2. 进入「插件市场」
3. 点击「上传插件」
4. 选择打包好的 `astrbot_plugin_foot.zip`
5. AstrBot 自动安装并加载

方法二：Git 安装

1. 在 WebUI「插件市场」→「安装插件」→ 填入本仓库地址
2. 等待安装完成

方法三：手动安装

1. 将本仓库内容放到 `data/plugins/astrbot_plugin_foot/`
2. 重启 AstrBot
3. 在 WebUI 中启用插件

⚙️ 自定义内容

插件无需 WebUI 配置，角色文案与图片都在插件目录内，直接改文件即可：

| 文件 | 作用 |
|------|------|
| `data.py` | 角色列表 `CHAR_ROWS`、通用故事 `STORIES`、口感 `TASTE`、专属文案 `CUSTOM` |
| `images/` | 脚部裁剪图，文件名 `char_XXX_名_1.jpg` |

添加角色专属文案

编辑 `data.py` 里的 `CUSTOM` 字典，照格式加一条：

```python
CUSTOM = {
    "某个角色名": {
        "story": "这个角色的脚臭吧风味故事……",
        "taste": "尝起来香香软软的。",
    },
}
```

添加/替换立绘

把脚部裁剪图放进 `images/`，文件名用 `char_XXX_名_1.jpg` 格式（与 `CHAR_ROWS` 里的一致）。重启插件生效。

说明

- 角色名在 `CHAR_ROWS` 里没有的，不会参与随机抽取
- 图片格式 jpg / jpeg / png 都支持（代码里按 `.jpg` 后缀读取，用其他格式记得同步改 `main.py`）

触发示例

以下消息都能触发：
- `看看脚`
- `/看看脚`
- `@机器人 看看脚`
- `看看脚 bot名`（点名）
- `看看足` / `看看jio`

🔧 技术细节

- 触发方式：`@filter.command`（标准指令）+ `@filter.regex`（裸关键词，不受唤醒前缀限制）
- 不需要@：群聊直接发「看看脚」即可触发（v2.0.0）
- 立绘来源：AstrBot 官方精一立绘资源镜像 `Aceship/Arknight-Images`，裁剪底部 30% 并裁透明留白
- 图片本地发送：`Comp.Image.fromFileSystem` 直接读插件目录，不依赖外链、不吃服务器带宽
- 群组/私聊：都支持
- 概率说明：角色与故事/口感均随机，每次回复都不一样

🐛 故障排除

插件加载失败
1. 检查文件是否完整（`main.py`、`data.py`、`metadata.yaml`、`_conf_schema.json`、`images/`）
2. 确认 AstrBot 版本 `>=4.16,<5`
3. 查看日志中的错误信息

不触发回复
1. 确认插件已启用
2. 群聊裸发「看看脚」应该能触发（v2.0.0 起）；若不行，试试 `/看看脚` 或 @机器人
3. 检查是否有其他插件抢占了消息

只出文字不出图
1. 确认 `images/` 目录存在且有 `.jpg` 图片
2. 检查图片文件名是否与 `data.py` 里 `CHAR_ROWS` 的文件名一致

想加自己的图/文案
- 直接改 `data.py` 和 `images/`，见上方「自定义内容」
